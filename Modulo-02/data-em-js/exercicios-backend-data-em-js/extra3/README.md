# Exercício extra 🌟

## Formatando datas

Faça funções que recebam um `Date()` como argumento e formate a data, retornando um string como nos exemplos abaixo (uma função para cada letra):

a) `05 de outubro de 2020`
b) `05/10/2020`
c) `5 out`
d) `05 out 2020`
e) `05 de out de 2020`
f) `05/out`
